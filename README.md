# Kolejka piosenek

Aplikacja (PWA) z jednym przyciskiem, który puszcza wszystkie piosenki z listy z YouTube po kolei.
Działa w przeglądarce, da się ją zainstalować na telefonie i komputerze, lista zapisuje się lokalnie.

## Publikacja na GitHub Pages
1. Wgraj wszystkie pliki z tego repozytorium (Add file → Upload files).
2. Settings → Pages → Source: „Deploy from a branch” → Branch: `main`, folder `/ (root)` → Save.
3. Po ok. minucie aplikacja jest pod `https://TWOJ-LOGIN.github.io/NAZWA-REPO/`.

## Instalacja
- Android (Chrome): menu ⋮ → „Zainstaluj aplikację”.
- iPhone (Safari): Udostępnij → „Dodaj do ekranu początkowego”.
- Komputer (Chrome/Edge): ikona instalacji w pasku adresu.

Po zmianie plików podbij numer wersji `CACHE` w `sw.js`, żeby użytkownicy dostali aktualizację.
